# Медиатека — офлайн-плеер для iPhone

PWA-плеер в стиле Apple Music: вы добавляете аудиофайлы из приложения «Файлы»,
они сохраняются в медиатеке (IndexedDB) и играют без интернета и компьютера.

## Как это работает

- Файлы **копируются** в хранилище приложения при импорте.
- Играет обычный `<audio>` + Blob URL, поэтому работают блокировка экрана,
  пульт на экране блокировки и фоновое воспроизведение (Media Session).
- Оригиналы в «Файлах» остаются на месте — это ваша резервная копия.

## Тёмная и светлая тема

Тема следует системной настройке iPhone («Настройки → Экран и яркость»)
или переключателю в «Пункте управления». Своего переключателя в приложении нет.

- обе палитры живут в `styles.css`: тёмная — в `:root`, светлая — в
  `@media (prefers-color-scheme: light)`;
- при смене темы в системе уже открытое приложение перекрашивается сразу,
  перезапуск не нужен;
- `theme-color` в `index.html` продублирован под обе схемы, чтобы цвет
  строки состояния совпадал.

Если в светлой теме время и заряд наверху плохо читаются (iOS рисует их
белыми из-за `black-translucent`), замените в `index.html`
`apple-mobile-web-app-status-bar-style` на `default`.

## Где взять музыку на iPhone

Подойдут MP3, M4A/AAC, WAV, FLAC, OGG/OPUS, AIFF, CAF.

Способы положить файлы в «Файлы»:

- AirDrop с Mac/iPhone → «Сохранить в Файлы»;
- Finder → iPhone → «Файлы» (общий доступ к файлам);
- Telegram: у файла «Поделиться» → «Сохранить в Файлы»;
- скачать в Safari → «Загрузки»;
- iCloud Drive.

**Важно:** музыка из приложения «Музыка» (Apple Music, треки, синхронизированные
через Finder/iTunes) недоступна веб-приложению — iOS не даёт сайтам доступ к
медиатеке. Если музыка лежит только там, её нужно сначала выгрузить в «Файлы»
(или делать отдельное нативное приложение).

## Локальный запуск

```bash
cd player
python3 -m http.server 8090
```

Открыть `http://localhost:8090` на Mac. Service worker работает только на
`localhost` или `https://`, поэтому по `http://192.168.x.x` офлайн-режим не проверить.

## Публикация и установка

1. Выложить папку `player` на любой бесплатный https-хостинг:
   - `npx surge .` из папки `player` (даст поддомен вида `my-music.surge.sh`);
   - либо перетащить папку на <https://app.netlify.com/drop>;
   - либо GitHub Pages.
2. На iPhone открыть адрес **в Safari** → «Поделиться» → «На экран “Домой”».
3. Запустить с иконки, нажать «Добавить музыку» и выбрать треки в «Файлах».
4. Проверить офлайн: включить авиарежим и запустить приложение.

## Обновление

1. Изменить файлы.
2. В `sw.js` поднять версию: `music-player-v5` → `music-player-v6`.
3. Переопубликовать.
4. Открыть приложение один раз с интернетом.

## Ограничения iOS

- Плеер не читает медиатеку «Музыка» — только файлы, добавленные вручную.
- Громкость регулируется кнопками телефона: iOS игнорирует `audio.volume`.
- Хранилище ограничено свободным местом; при нехватке места импорт остановится
  с сообщением. Держите оригиналы в «Файлах».
- Очистка данных Safari («Настройки → Safari → Очистить историю и данные»)
  удалит и библиотеку приложения.
